Natasha Litherland portfolio

index.html is the whole website in one file: every image and the CV are built in.
To put it online, upload index.html to any static host (GitHub Pages, Netlify, etc.).
Natasha_Litherland_CV.pdf is the same CV the download button offers.

source/ holds the parts index.html is assembled from, if you want to edit them:
  cat part1.html photos.js photos2.js photos3.js work_data.js part2.html > index.html
